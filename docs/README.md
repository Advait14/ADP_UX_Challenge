## Prototype

Open [../index.html](../index.html) in a browser to run the interactive prototype.

## Local development

From the project folder, run:

```bash
npm install
npm run dev
```

Vite will show the local address in the terminal. Use `npm run build` to create a production-ready static build in `dist/`.
