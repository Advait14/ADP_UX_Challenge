# Demo Script

## Suggested 3–4 minute walkthrough

1. **Frame the problem:** A recruiter must process high volume without turning a score into a hiring decision.
2. **Open Today’s work:** Explain that the dashboard answers what needs a decision, who has waited longest, and which updates require approval.
3. **Open Candidate queue:** Demonstrate the working filter and sort controls. Point out that evidence signal and waiting time appear before any score.
4. **Select Rohan:** Open the review drawer and explain that his application initially had low evidence confidence, so the system did not reject him.
5. **Review assessment:** Show the completed customer-response assessment and how it adds new job-related evidence.
6. **Open full evidence:** Verify source evidence, gaps, system inputs, and excluded attributes.
7. **Choose next step:** Shortlist, clarify, assess, or do not progress. Demonstrate that an override requires a job-related reason.
8. **Preview candidate update:** Show outcome-specific, editable communication and the prototype-only notice.
9. **Show decision history:** Explain how recommendation, assessment, recruiter action, override, and communication approval are traceable.
10. **Show shortlist handoff:** Explain that the hiring manager receives only decision-relevant evidence and recruiter rationale.
11. **Close with success:** The concept reduces repetitive work while leaving meaningful screening decisions with the recruiter.
