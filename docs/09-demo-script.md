# Demo Script

## Suggested 3–4 minute walkthrough

1. **Frame the problem:** A recruiter must process high volume without turning a score into a hiring decision.
2. **Open Today’s work:** Explain that the dashboard is a worklist, not an analytics page. It focuses on decisions, clarifications, and assessment results.
3. **Open Candidate queue:** Show the action-first filters and selected-candidate preview. Point out that score is not the hero.
4. **Select Rohan:** Explain the low-confidence scenario: relevant retail service evidence exists, but direct CRM evidence and shift confirmation are missing.
5. **Open full review:** Verify the source evidence and show what the system used and excluded.
6. **Choose next step:** Send the structured assessment instead of rejecting. Explain that only a recruiter can approve the action.
7. **Preview candidate update:** Show that it is editable, respectful, and includes an alternative-format support route.
8. **Show timeline:** Explain the auditability of recommendation, recruiter approval, and candidate update.
9. **Show shortlist brief:** Explain that the hiring manager gets only decision-relevant evidence and recruiter rationale.
10. **Close with success:** The concept reduces repetitive work while leaving the recruiter in control of meaningful decisions.
